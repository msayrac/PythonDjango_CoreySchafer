# Full-Stack Django Blog Application

## Tech
* Backend: Python 3.12, Django 6.x
* Database: SQLite (Development standard with relational design)
* Frontend UI: HTML5, CSS3, Bootstrap 4
* Form Layouts: Django Crispy Forms (with crispy-bootstrap4 engine)


## Core Features
* User Authentication System: Secure custom User Registration, Login, and Logout flows powered by Django's built-in authentication system.
* Dynamic Profile Management: Automatically generates a user profile upon registration using Django Signals (post_save), complete with profile picture uploads.
* Class-Based Views (CBVs): Leveraged advanced Django CBVs (ListView, DetailView, CreateView, UpdateView, DeleteView) to implement clean, highly reusable CRUD operations for blog posts.
* Granular Security Controls: Integrated LoginRequiredMixin and UserPassesTestMixin to enforce absolute security—ensuring only the authentic author of a post can update or delete it.
* Pagination & Sample Data: Handled heavy database content efficiently using Django Pagination and seeded the DB with bulk mock data via customized JSON fixtures (loaddata).
